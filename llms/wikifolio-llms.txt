# wikifolio

> wikifolio (wikifolio Financial Technologies AG) is a European social- and copy-trading
> platform where experienced traders publish transparent virtual portfolios ("wikifolios")
> that everyday investors can follow, compare, and — in Germany, Austria, and Switzerland —
> invest in via exchange-listed wikifolio certificates bought through a bank or broker.

wikifolio was surfaced as a portfolio company of Speedinvest and is profiled in the API
Evangelist network. As of this writing wikifolio does not appear to publish a public
developer API, OpenID/OAuth authorization server, `.well-known` API catalog, or `llms.txt`
of its own; this file is generated from the catalog profile rather than fetched from the
provider.
